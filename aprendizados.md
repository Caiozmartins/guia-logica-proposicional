\# Aprendizados do Projeto



\## Visão geral



Durante o desenvolvimento deste projeto, utilizei Git e GitHub para organizar, versionar e estruturar um guia de aprendizagem em Markdown.



O tema escolhido foi lógica proposicional e tabelas-verdade, com foco em estudantes iniciantes.



\## Uso de branches



Aprendi a criar branches para separar diferentes partes do desenvolvimento do projeto.



Foram utilizadas branches com nomes descritivos, como:



\* `feature/conceitos`

\* `feature/exercicios`

\* `feature/ajuste-readme`



Essa organização permitiu desenvolver conteúdos de forma separada antes de integrá-los à branch principal.



\## Commits



Durante o projeto, foram realizados commits com mensagens claras e padronizadas.



Isso tornou o histórico mais organizado e facilitou a identificação das alterações realizadas em cada etapa.



\## Merge



Utilizei o comando `git merge` para integrar as alterações desenvolvidas nas branches à branch `main`.



Também utilizei o histórico em formato de grafo para visualizar como as branches foram criadas e integradas.



\## Resolução de conflito



Foi criado um conflito controlado no arquivo `README.md`.



O conflito ocorreu porque a branch `main` e a branch `feature/ajuste-readme` alteraram a mesma frase.



Analisei as duas versões, removi os marcadores de conflito e combinei as informações em uma versão final coerente.



\## Pull Request



O projeto também utiliza o conceito de Pull Request para revisar alterações antes de integrá-las à branch principal.



O Pull Request permite documentar as mudanças, realizar revisão e verificar se o conteúdo está pronto para ser integrado.



\## Conclusão



O projeto ajudou a compreender de forma prática como Git e GitHub podem ser utilizados em um fluxo real de desenvolvimento.



As principais habilidades praticadas foram criação de branches, commits, merge, resolução de conflitos, organização do histórico e colaboração por meio de Pull Requests.
